## 論文に書いたこと

論文のタイトルは「家庭で実践可能なシリコーンゴム造形と型設計支援ツール」です。

シリコーンゴムは型取りの材料としてはよく使われますが、シリコーンゴムそのものを作品として家庭で造形するための情報は、調べた範囲では多くありませんでした。
家庭での造形には、硬化阻害を踏まえた材料選び、シリコーンより硬い型の製作、型の設計という3つの難しさがあります。
論文では、家庭で手に入る材料と3Dプリンターで再現できる造形の手順を、必要な条件と失敗例に絞って整理しました。
あわせて、型の設計を支援するBlenderアドオン「Silicone Casting」も報告しています。

論文の各節と、このシリーズの記事の対応は次のとおりです。

| 論文の節               | 対応する記事                                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 2.1 シリコーンゴム     | [その1「シリコーンゴムを選ぶ」](/blog/silicone-series-choosing-silicone-rubber/)                                 |
| 2.2 資材と機材         | [その2「シリコーン造形に必要なもの」](/blog/silicone-series-what-you-need/)                                      |
| 3.1 型設計支援アドオン | [番外編「Blenderアドオンを作った」](/blog/silicone-series-blender-addon/)                                        |
| 3.2 型の設計と造形     | [その4「型を作成する」](/blog/silicone-series-making-mold/)、[その5「造形する」](/blog/silicone-series-casting/) |
| 3.3 着色試験           | [その3「シリコーンに着色する」](/blog/silicone-series-coloring/)                                                 |

ブログとの違いは、主に次の3点です。

- 付加型シリコーンの硬化阻害やショアA硬度、PLA樹脂の型について、メーカーの資料や先行研究を引用して裏付けた
- アドオンの着色シミュレーションで使っている、色の混ぜ方と透明度の計算式を載せた
- 硬化不良の原因、着色剤の量、家庭での造形を広めるための課題を考察した

一方で、作業の写真や操作の細かい手順はブログに任せています。手を動かすときは、各回の記事をあわせて読んでください。
